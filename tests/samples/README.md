# XYZ test files

Real XYZ files that the tests load. They are unchanged copies, taken at commit `1d3772857e` of three.js.

| Files | What they cover | Source and licence |
| --- | --- | --- |
| `helix_201.xyz` | A helix of 201 points | The [three.js](https://github.com/mrdoob/three.js) repository (`examples/models/xyz`), under its [MIT licence](https://github.com/mrdoob/three.js/blob/dev/LICENSE); no other licence is stated for them. |

The tests also write files with colours, intensity and normals.

These files keep their own licences. They are test data only, and are not part of the npm package, which includes only `dist`, `Documentation`, `README.md` and `LICENSE`.
